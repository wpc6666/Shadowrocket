Shadowrocket 配置

小火箭（Shadowrocket）iOS 代理工具配置集，含分流规则、策略组、DNS 与 URL 重写。一键订阅，自动更新。

订阅地址 GitHub 仓库

📦 里面有什么

🧭 分流规则
44 条规则，覆盖常见国内外站点，按域名 / IP 段 / 地区分流。
⚖️ 策略组
16 个 url-test 自动测速组，按地区（韩国 / 日本 / 美国等）自动选最快节点。
🌐 DNS 与防泄漏
国内 DoH + 国际 DoH 双通道，含 dns_exclusion_list 防污染。
✏️ URL 重写
内置 URL Rewrite 与 MITM 段，可按需启用。

🚀 怎么用

  1. 在 iPhone 上安装 Shadowrocket（App Store 美区 / 港区，需付费）。
  2. 打开 App → 首页右上角 + → 类型选 Subscribe。
  3. URL 填下面这个地址，保存后下拉更新。
  4. 选中刚加的配置 → 打开顶部开关即可。
# 订阅地址（复制到 Shadowrocket 的 Subscribe）
https://raw.githubusercontent.com/wpc6666/Shadowrocket/refs/heads/main/2025.5.17.conf

⚙️ 配置结构

段落作用
[General]全局开关：IPv6、DNS、bypass-tun 内网直连、skip-proxy 排除列表
[Proxy Group]策略组：按地区做 url-test 自动测速选优
[Rule]分流规则：域名 / IP 段 / 地区匹配后走指定策略
[URL Rewrite]URL 重写规则（按需启用）
[MITM]HTTPS 中间人解密，配合 URL Rewrite 使用

⚠️ 注意事项

本仓库不含任何节点信息。只有分流规则和策略组配置，节点需自备（从你自己的机场或自建服务器导入）。

MITM 与 URL Rewrite 默认关闭。开启后 App 会解密 HTTPS 流量，请只对你信任的站点启用，并确认已安装并信任证书。

  • 规则会随上游列表变化，建议每周更新一次。
  • 遇到某站点无法访问，先看是不是规则把它判到了「直连」。
  • 配置文件为纯文本，可以直接编辑后本地导入。
